## Project Description
This project is a Cloud-Based Task Management Application developed using Scrum methodology. 
The system allows users to create tasks, assign tasks to users, and track task completion. 
The project simulates a one-sprint Scrum workflow as part of the IS 384 – Cloud and DevOps course.
